## Project Title
Chess Console System 

## Description
Welcome to the Chess Console System!! Each piece has its own movement's rules and when it's your turn to play, 
the board will highlight the possible moves for the chosen piece. 
I hope you really enjoy it!
![QueensGambit](https://images.chesscomfiles.com/proxy/telltaletv.com/wp-content/uploads/2020/12/QueensGambit/https/ce5dcc6264.gif)

## Pre Requirements
In order to starting playing chess, you need to follow the instructions below to have a complete experience: 

- [X] Download the required Java Version using this link: [Oracle Java](https://www.oracle.com/br/java/technologies/downloads/#java17-linux);
- [X] Install the Java 17 by adopting the behaviour: next, next, next and finally install it;

Then, you'll have all the pre requirements needed. 

## Clone the project

- [X] Access the following Github link, copy the URL's project https://github.com/marcelybigsantello/Chess-System-Java.git 
- [X] Open any Terminal on your computer: you may use Command Line (CMD) or Powershell Terminal
- [X] Type the following command: git clone https://github.com/marcelybigsantello/Chess-System-Java.git
- [X] Congratulations! You just cloned the project to your local computer! 

## Start playing
- [X] Navigate to the target folder where the project was cloned in the step before.
Example: C:\temp\chess-system\
- [X] Enter the \bin folder 
- [X] Execute the following command: java application/Program.
If you tab, please make sure to delete the extension from the Program file. Ex: Program~~.class~~~

Have fun my dear!!
